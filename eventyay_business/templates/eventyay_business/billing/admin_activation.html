{% trans 'Consolidated billing activation' %}

{% blocktranslate trimmed %} Activation records the organizer’s cutover time. Ticket payments completed after that time accrue fees in the Business ledger, and the monthly task generates and collects Eventyay invoices for that organizer. {% endblocktranslate %}

{% trans 'Before activation' %}
  1. {% trans 'Create the organizer’s canonical Stripe billing customer.' %}
  2. {% trans 'Save a payment method for that customer.' %}
  3. {% trans 'Have the organizer save a payment method and accept automatic payments in the same action.' %}
  4. {% trans 'Cancel every legacy Stripe plan and add-on subscription so it cannot charge independently.' %}
  5. {% trans 'Run reporting mode and explicitly accept the latest reconciliation result.' %}

{% blocktranslate trimmed %} Activation is intentionally one-way. If the payment method or authorization is later removed, invoice generation continues but automatic collection pauses until the billing setup is repaired. {% endblocktranslate %}
